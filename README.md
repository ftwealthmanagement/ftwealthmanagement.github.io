# Global Macro & Asset Allocation Analysis

An interactive, self-contained single-page dashboard covering the global macro economy and asset allocation views across six chapters:

1. Global Macro Analysis — four economies (US / China / Japan / Euro area) and their central banks
2. Global Equity Review — six indices: overview, range returns, trends, valuations and technicals
3. Fixed Income — US Treasury yield curve and credit spreads (IG / HY / CCC)
4. Commodities & Alternatives — gold and bitcoin
5. Overall Summary — core judgment, risk factors and an allocation matrix with a curated fund list
6. Selected Institutional Views

Features: full Chinese/English toggle (top-right), light/dark themes, hoverable charts, zero external dependencies (pure inline SVG, no CDN).

Data as of 2026-10-14. Sources are documented in the page footer. Research reference only — not investment advice.
